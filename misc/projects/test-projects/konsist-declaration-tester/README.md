# Konsist Path Tester

This project is used to test Kotlin file querying logic:
- test `hasTest` logic
- test `module` and `sourceSet` logic
- test `KoChildDeclaration`
- test file paths in error output and scope `toString`/`print`

Test project contains [root](.) module and four submodules ([app](.\app), [data](.\data), [feature](.\feature) and
[feature/payment](.\feature\payment) nested inside it). 

For Konsist sample projects see
the [konsist-sample-projects](https://github.com/LemonAppDev/konsist-sample-projects/) repository.
